# ЗАДАЧА 1. ГИБРИД «ГАЛСТУК-БАБОЧКА» (FTA слева + ETA справа)

Главная задача сессии. Сейчас дерево — чистый ETA от уровня 0 направо. Достроить слева Дерево отказов (FTA): причины и критерии появления ГС (горючей среды) и ИЗ (источника зажигания), обуславливающие их СОВМЕСТНУЮ реализацию в центре. Итог — гибридная модель слева направо через центр, связывающая частоту Q и сценарии пожара:

```
уровни:  −5 … −1  |  0                    |  1 … 5
         ДЕРЕВО ОТКАЗОВ (FTA)             |  ДЕРЕВО СОБЫТИЙ (ETA)
         причины/критерии ГС и ИЗ         |  барьеры/сценарии пожара
                     └── И-гейт ──► ПРОЛИВ/ВЫБРОС/ОБРАЗОВАНИЕ ГС+ИЗ ──► …
```

**Логика связности (обязательна, «как в ГОСТе и в методике»):**
- Левая сторона — ДВЕ монотонные фазовые цепи: фаза ГС (критерии/причины образования горючей среды) и фаза ИЗ (критерии/причины появления источника зажигания), сходящиеся И-гейтом в центральное событие уровня 0 «ГС + ИЗ» (совместная реализация).
- Порядок фиксирован и не чередуется: путь от листа-причины к центру идёт **ГС → ИЗ → ГС+ИЗ** либо **ИЗ → ГС → ГС+ИЗ**. События фазы ГС не могут перемешиваться с событиями фазы ИЗ (никакого «ГС, ИЗ, снова ГС» на одном пути).
- Это правило enforcement'ится валидатором (Smart Linking): DnD причины не той фазы на узел другой фазы — отказ с понятной причиной (плашка HintItem); на path_tags завести фазовые теги (`phase:gs`, `phase:iz`) по образцу `required_parent_tags/incompatible_tags`.
- Повтор одного и того же события-причины на одном пути запрещён (классика FTA).
- Раскладка уровней: например −5…−3 — фаза 1, −2…−1 — фаза 2, 0 — центр (порядок фаз может выбираться пользователем при построении, но внутри пути чередования нет). Эшелоны −5…−1 — в БЗ с заголовками.

**Математика:**
- Причины-листья: частота/вероятность Q_i (год⁻¹) из БЗ (с полем source).
- Гейты: И → `Q = ∏ Q_i`; ИЛИ → `Q = 1 − ∏(1−Q_i)` (выбор формулы ИЛИ зафиксировать в коде, документации и тестах; допустима аппроксимация Σ для редких событий — тогда явно это указать). Гейт — узел с бейджем «И»/«ИЛИ».
- Q центрального события уровня 0 = выход И-гейта двух фаз (при независимости: `Q_ГС · Q_ИЗ`); если левой части нет — как сейчас, из `q_spec` инициирующего события (старое поведение сохраняется).
- Инварианты (проверить тестами): на ETA-стороне по-прежнему ΣP=1 на развилке и ΣQ листьев = Q_центра; на FTA-стороне — формулы гейтов; полное дерево: ΣQ сценариев = Q_центра.
