## ЗАДАЧА 4. Маппинг записей (правила заполнения полей)

| Поле cause_events | Правило |
|---|---|
| `id` | `c-gs-<оборудование>-<узел>` / `c-iz-<оборудование>-<узел>`, латиница, дефисы; уникальность проверяй |
| `title` | «Итоговое событие отказа» из md (без изменений) |
| `level` | −5 (первичные поломки/деградация узлов); для внешних природных воздействий (ветер, снег, молния, паводок) – уровень существующих аналогов (см. `c-gs-ground-movement`); для отказов систем/автоматики (отказ реле, АВР, датчика тяги) – уровень по аналогии с существующими `c-*` |
| `phase` | класс ГС → `"gs"`; ИЗ → `"iz"`; ГС+ИЗ → `"iz"` + тег `gs-precondition` + notes «одновременно образует ГС» |
| `kind` | `"cause"` |
| `q_type` / `freq_mode` | `"freq"` / `"direct"` (per_meter – только для линейных объектов: эстакады, трубопроводы на эстакаде) |
| `q_init` | только из Пула А |
| `source` | по Задаче 2 |
| `tags` | `[gs|iz, <equipment: pump/compressor/turbine/fan/conveyor/diesel/vessel/column/reactor/separator/filter/rvs/avo/flare/oru/bmk/estacada>, <узел: seal/bearing/valve/insulator/roof/bottom/flange/...>]` |
| `notes` | «Механизм или причина (→ ГС/ИЗ)» + реконструкция функции из «Исходного события надёжности», если не «—» |

Опосредованные (раздел 5 md) → ТОЛЬКО в `pending_events` (phase по механизму), тег `indirect`.

Инициирующие события: если для типа оборудования из md в БЗ нет ни одного `init-*` (проверь: колонны/реакторы/сепараторы/фильтры/АВО/факел/ОРУ/БМК/эстакады), создай обобщённые `init-<тип>-leak` (уровень 0, «Разгерметизация/выброс …») с частотой из табл. П1.1 Методики 533 по ближайшей группе + notes-ссылку на md-БЗ; инициаторами НЕ делай ИЗ-события (центр «бабочки» – потеря герметичности/выброс, воспламенение – справа).
