## 1. Методика

### 1.1. Правила инверсии (сохранены от сбора)

| Оборудование | Событие надёжности | Событие отказа (антагонист) |
|---|---|---|
| Наружный трубопровод | Сохранение текучести среды при морозе | Замерзание среды и закупорка сечения |
| Колонный аппарат | Герметичность фланцев под давлением | Разгерметизация фланцевого соединения |
| Насосный агрегат | Вибрация подшипников в пределах нормы | Превышение предельного уровня вибрации |
| Градирня (наружная) | Защита конструкции от обледенения | Критическое обледенение жалюзи и оросителя |

Терминология — ГОСТ 27.002-2015. Прямые отказы: в графе «Исходное событие надёжности» — прочерк или реконструкция нарушенной функции.

### 1.2. Критерии фильтра ГС/ИЗ

**Класс ГС** — отказ прямо ведёт к образованию горючей среды:
- выход (утечка, пролив, выброс) горючего газа, ЛВЖ/ГЖ, углеводородной среды наружу;
- переток/смешение сред с образованием взрывоопасной смеси внутри аппарата (включая подсос воздуха в газовую систему);
- выброс горючей пыли в воздух (аэровзвесь), масляный туман в сжатом воздухе;
- поступление CO и несгоревшего топлива в помещение;
- срыв/погасание пламени (факел, горелка) с выходом негоревшего горючего газа.

**Класс ИЗ** — отказ прямо создаёт источник зажигания:
- электрическая дуга/искра: перекрытие и пробой изоляции, межвитковое замыкание, обрыв цепи под нагрузкой, неполный контакт;
- перегрев контактов и токоведущих частей;
- фрикционное искрообразование и нагрев трения (проскальзывание ленты, проворот колеса на валу, задевание ротора);
- тление/самовоспламенение масляных отложений (компрессоры), перегрев масла и стенок;
- горячие поверхности (перегрев стенок котла, расплавление баббита, раскалённые продукты сгорания, поздний впрыск топлива);
- открытое пламя, воздействующее на соседнее оборудование (снос факела).

**Класс ГС+ИЗ** — отказ создаёт одновременно и то, и другое.

**Допущения:**
1. Для оборудования, среда которого определяется проектом (насосы, компрессоры, теплообменники, сепараторы, фильтры, АВО, факел, РВС, эстакады), отнесение к ГС дано в предположении горючей (углеводородной) среды. Для водяных/паровых контуров те же отказы ГС не образуют.
2. Внутренний объём аппаратов с горючей средой штатно содержит ГС; запись классифицируется как ГС только при выходе среды наружу или образовании смеси с воздухом, и как ИЗ — при появлении внутри неё источника зажигания.
3. Отказы без выхода среды и без энергетического проявления (падение КПД, дисбаланс, осадка, обледенение, деградация) удалены; часть из них, образующих ГС/ИЗ при коротком развитии сценария, вынесена в раздел 5 «Пограничные (опосредованные)».

## 5. Пограничные (опосредованные) отказы — образуют ГС/ИЗ при коротком развитии сценария

Прямой эффект отказа не образует ГС/ИЗ, но создаёт их при развитии; оставлены отдельным списком для анализа деревьев событий.

| Категория и тип | Отказ из собранной БЗ | Опосредованный механизм ГС/ИЗ |
|---|---|---|
| Аппарат: Сосуд под давлением | Водородная коррозия, охрупчивание | Внезапное хрупкое разрушение → ГС |
| Аппарат: Сосуд / РВС | Язвы сверх допуска; утонение 1-го пояса | Развитие до сквозного пропуска → ГС |
| Аппарат: Колонна | Утонение штуцеров и люков | Пропуск по штуцеру → ГС |
| Аппарат: Реактор с мешалкой | Выбивание пара через узел вала | При горючей среде — унос парогазовой фазы → ГС |
| Агрегат: Компрессор винтовой | Заклинивание винтового блока | Динамическое разрушение с нагревом → ИЗ |
| Агрегат: Турбина паровая | Разрегулирование САР: заброс оборотов | Разнос ротора, разрушение с искрами → ИЗ |
| Агрегат: Компрессор центробежный | Разрушение упорного подшипника | Перегрев в масляной среде → ИЗ |
| Наружная установка: АВО | Ослабление затяжки крепежа → разрушение ступицы | Задевание вентилятора, искры → ИЗ |
| Наружная установка: ОРУ | Излом опорного изолятора при переключениях | Обрыв ошиновки → дуга → ИЗ |
| Наружная установка: БМК | Размерзание труб и импульсных линий КИП | Последующая негерметичность газа/теплоносителя → ГС |
| Наружная установка: БМК | Заклинивание ЭПЗА (ГРУ) | Невозможность отсечки газа при опасном режиме → ГС |
